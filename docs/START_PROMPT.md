# Startprompt til Claude Code

Læg mappen med `CLAUDE.md`, `docs/` og `prototype/` i dit tomme `hutel`-repo, åbn det i VS Code, start Claude Code og indsæt teksten herunder.

---

Hej Claude. Vi skal bygge multiplayer-udgaven af mit spil Hutel.dk.

Læs først `CLAUDE.md`, `docs/PLAN.md` og `prototype/index.html` grundigt. Prototypen er en fungerende enkeltspiller-version, og dens udseende, figurer, møbler og lys er facitlisten.

Vi starter med **Milepæl 0** og derefter **Milepæl 1** i `docs/PLAN.md`.

Sådan vil jeg have, at du arbejder:

1. Skriv først en kort plan for Milepæl 0 og vent på mit ok.
2. Byg i små skridt med en commit pr. skridt.
3. Når en opgave er færdig, så markér den med ✅ i `docs/PLAN.md` og flyt den ned under de færdige punkter.
4. Spørg mig, før du opretter eksterne konti, tilføjer betalte tjenester eller har brug for nøgler. Sig præcis, hvad jeg skal oprette, og hvilke værdier jeg skal lægge i `.env`.
5. Skriv til mig på dansk.

Når Milepæl 1 er færdig, vil jeg kunne logge ind fra to computere og se hinanden gå rundt og chatte i lobbyen.
